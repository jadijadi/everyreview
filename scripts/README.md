# Scripts

Cross-cutting developer and operations scripts that don't belong to a single component.

Planned:
- `generate-api-clients.sh` — regenerate the Android (and later iOS) API client code from `backend/api/openapi.yaml`.
- `setup-dev-env.sh` — bootstrap a local dev environment (docker compose up, run migrations, seed data).
- `new-adr.sh` — copy `adrs/template.md` to the next sequentially numbered ADR file.
